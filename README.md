# Aura Temp & Humid

Build a modern responsive Temperature and Humidity Monitoring website for an IoT project.

Create the frontend dashboard using React and Tailwind CSS.

The website will eventually receive real-time temperature and humidity data from an IoT sensor through an API/backend, but do not implement the IoT connection or API yet.

For now, use realistic dummy data.

Features:

- Temperature card showing current temperature in °C

- Humidity card showing current humidity in %

- Status indicators (Normal/High/Low)

- Temperature and humidity charts

- Current date and time

- Sensor connection status

- Dashboard, History and Settings pages

- Mobile and desktop responsive design

- Modern IoT dashboard UI

- Blue and green theme

Keep data separate from UI so I can connect an IoT sensor API later.

Add comments showing where future API integration will happen.
